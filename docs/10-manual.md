## 1. Что делает система

**TrendScout** отвечает на вопрос: *кто из исполнителей начинает по-настоящему набирать
популярность прямо сейчас* — до того, как это заметит рынок.

Каждую неделю система получает выгрузки прослушиваний с площадок, строит чарты по регионам
и проверяет их тремя правилами. Если правило сработало — создаётся **сигнал** с объяснением:
какое правило, на каких данных, с какой уверенностью.

Данные в проекте учебные: сгенерированы детерминированно (seed 20261109), результаты
воспроизводимы. Логика решений, модель данных, контракт API и тесты — как в боевой системе.

### Три типа прорыва

| Тип | Простыми словами | Кому полезно |
|---|---|---|
| **NEWCOMER** — новичок | Дебютировал недавно и сразу попал в топ | A&R лейбла |
| **SLEEPER** — спящий каталог | Каталог давно доступен, слушали мало — и вдруг топ | A&R, каталог-менеджмент |
| **VIRAL** — медиа-всплеск | Рост совпал с фильмом, сериалом, трендом | Маркетинг, букинг |

### Стейкхолдеры

- **Концертное агентство** — понять, в каком регионе растёт аудитория, спланировать тур.
- **A&R-менеджер лейбла** — найти перспективного исполнителя раньше конкурентов.
- **Маркетинг** — отличить устойчивый рост от короткого хайпа.

```powershell
cd D:\BASAProjects\trendscout\backend
.venv\Scripts\activate

```
